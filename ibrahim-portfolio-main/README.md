## 🚀 About the Project

A modern, fully responsive, and bilingual (English / Arabic) **personal portfolio website** built from scratch with **Vanilla HTML, CSS, and JavaScript** — no frameworks, no libraries.

The portfolio showcases my skills, projects, and experience as a Front-End Developer, and includes a **Dark / Light theme toggle** with persistent user preference via `localStorage`.

> 🔗 **Live Demo:** [elghazaly-web.netlify.app](https://elghazaly-web.netlify.app/)

---

## ✨ Features

### 🎨 Design & UX
- **Modern Bento Grid Layout** — inspired by Apple & Linear design systems
- **Ambient Animated Background** — 3 floating gradient blobs + subtle grid overlay
- **Glassmorphism** UI elements with backdrop blur
- **Custom gradient text** and smooth color transitions
- **Fully responsive** — works beautifully on mobile, tablet, and desktop

### 🌗 Theme System
- **Dark / Light mode** toggle
- Persists user preference with `localStorage`
- Instant theme application with no flash of unstyled content (FOUC)

### 🌍 Bilingual Support (i18n)
- **Full English + Arabic** support
- Automatic **RTL** layout switch when Arabic is selected
- Custom **Cairo** font loaded for Arabic typography
- Persistent language preference with `localStorage`

### ⚡ Interactive Features
- **Skill bars** — animated fill on scroll using `IntersectionObserver`
- **Scroll reveal** animations for all sections
- **Active nav link** tracking based on scroll position
- **Smooth scrolling** with navbar offset
- **Mobile menu** with staggered animations
- **Back to top** button with bounce-in animation
- **Contact form** integrated with **Formspree** (AJAX submission with validation)
- **Image fallback** — auto-generated SVG placeholders for broken images
- **Counter animation** for the stats section
- **Marquee tech strip** — infinite scroll of technologies

### 🎯 Sections Included
1. **Hero** — Intro with photo, CTA, and social links
2. **About** — Bento grid with bio, info, and a featured story card
3. **Services** — 4 service cards with icons
4. **Skills** — Two panels with animated progress bars
5. **Projects** — 6 project cards with hover overlays
6. **Experience** — Timeline with 4 entries (work + education)
7. **CTA Banner** — Call-to-action before contact
8. **Contact** — Form + contact info (Email, Phone, LinkedIn, GitHub, YouTube)
9. **Footer** — Quick links, social, and copyright

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Markup** | HTML5 (semantic) |
| **Styling** | CSS3 (Grid, Flexbox, Custom Properties, Animations) |
| **Interactivity** | Vanilla JavaScript (ES6+) |
| **Fonts** | Google Fonts — Inter, Cairo, JetBrains Mono, Space Grotesk |
| **Form Handling** | Formspree (AJAX endpoint) |
| **Icons** | Inline SVG (no icon library) |
| **Deployment** | Netlify / GitHub Pages / Vercel |

**Zero dependencies. Zero build step. Zero frameworks.**
